# Lambda CRM — лендинг по системе attio.com (монохром)

Отдельный проект: старый лендинг в корне папки не тронут.

## Запуск

```bash
cd "site-attio"
npm install     # один раз
npm run dev     # http://localhost:5175
```

Порт 5175, чтобы не конфликтовать со старым лендингом на 5174.
`npm run build` — прод-сборка в `dist/`, `npm run preview` — посмотреть собранное.

## Что где

```
src/
  data/content.ts        все повторяющиеся тексты: FAQ, кейсы, обновления, ячейки
  lib/hooks.ts           reveal, скролл-прогресс hero, scroll-spy «Ядра», сценарии демо
  lib/canvas.ts          сфера-горизонт и схема таблиц на canvas (тёмная глава)
  styles/tokens.css      цвета, шрифты, сетка, тени, кривые — вся система здесь
  styles/base.css        рамка страницы, типографика, кнопки, reveal
  styles/sections.css    раскладка секций и адаптив
  styles/demos.css       макеты интерфейса Lambda CRM внутри лендинга
  components/Demos.tsx   таблица, карточка, конструктор правил, роли, аналитика, гонка
  components/Ui.tsx      Reveal, иконки, wordmark
  sections/Top.tsx       шапка, hero, «Ушли к нам из»
  sections/Core.tsx      «Ядро» — навигация слева и пять групп с демо
  sections/Middle.tsx    внедрение, тёмная глава, цитата
  sections/Bottom.tsx    статистика, кейсы, обновления, FAQ, closing, футер
```

## Монохром

Цвета Attio заменены на свет и контраст: пилюля-kicker — серая заливка,
линия активного пункта навигации и кривая статистики — чёрные, небо в hero —
нейтрально-серое, ободок сферы — белый. Статусы внутри демо различаются
заливкой и обводкой (чёрный чип — событие, серый — нейтральный статус,
контурный — ожидание, контурный с точкой — просрочено), а не цветом.

## Движение

Приёмы сняты с лендинга docent (`~/Work/docent`) и переведены в монохром.
Framer Motion не подключали — всё сделано на IntersectionObserver, rAF и CSS,
поэтому в зависимостях по-прежнему только React.

- `src/lib/motion.ts` — повторяющийся reveal (blur 7px + 14px, играет при каждом
  возврате в кадр), счётчики, потоковый текст группами по 2–4 слова, наклон под
  курсором, закреплённый горизонтальный трек, тема шапки, орбита чипов и пауза
  для фоновой декорации за экраном.
- Hero: дрейфующая точечная сетка, медленно вращающийся диск, дышащие пятна,
  сабтайтл, который пишется по словам с бегущей кареткой, наклон и блик окна
  под мышью.
- Композер: `/` где угодно открывает поле, Enter собирает структуру из
  `src/data/structures.ts`, Esc возвращает. Незнакомый процесс получает типовой
  каркас и честную строку — это позиция, а не заглушка.
- Кейсы: секция закрепляется, карточки едут вбок по мере скролла, снизу — линия
  прогресса. При `prefers-reduced-motion` превращается в обычную прокрутку.
- Closing: вопросы клиентов дышат вокруг заголовка и тянутся к курсору.
- Всё движение выключается при `prefers-reduced-motion`.

## Что заменить перед публикацией

Ищите по `[` — метки видны прямо на странице:

- `src/data/content.ts` — цитата и имя клиента, числа `[N]` в кейсах, «было/стало»
  у клиентов 2 и 3, строка «Ушли к нам из», список обновлений, сроки и условия
  в FAQ (`[подтвердить]`).
- Форма в полосе «Разберём ваш процесс» сейчас только показывает «Спасибо» —
  отправку (почта, Telegram-бот или запись в саму CRM) нужно подключить
  в `src/sections/Bottom.tsx`, компонент `Updates`.
- Шрифты берутся из Google Fonts в `index.html` (Inter Tight / Inter /
  Source Serif 4 / JetBrains Mono).
