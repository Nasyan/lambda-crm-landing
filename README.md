# Lambda CRM — короткая интерактивная версия

Отдельная версия лендинга в монохроме Attio. Исходный проект `../site-attio` сохранён. Новая версия работает на http://127.0.0.1:5176/ с обновлением при сохранении файлов.

## Запуск

```sh
npm install
npm run dev
```

Проверка TypeScript и production-сборка: `npm run build`. Порт 5176 фиксирован, чтобы не подменять работающую исходную версию на 5175.

## Композиция и взаимодействия

1. **Зачем CRM.** Один оплаченный заказ, четыре ручных действия. Кнопка «Отметить оплату» выравнивает разрозненные карточки и последовательно запускает задачу, срок, списание и уведомление. Карточки раскрывают контекст; режим «Вручную» позволяет сравнить и повторить.
2. **Как связаны данные.** Вращаемая сфера показывает структуру магазина, кофейни или проектов. Можно перетаскивать, выбирать записи, приостанавливать движение и сбрасывать положение. Выбор новой записи поворачивает её к пользователю и обновляет инспектор. Стрелки клавиатуры вращают сферу, Home сбрасывает положение, двойной клик тоже сбрасывает.
3. **Что получает команда.** Три рабочих представления вместо перечня функций: выполнение задач меняет статус связанного заказа; менеджер переключает историю и договорённости; руководитель открывает проблемные заказы. Роли переключаются также стрелками клавиатуры, Home и End.
4. **Почему Lambda.** Готовое ядро и структура под процесс, которую собирает команда Lambda. Три этапа меняют рабочий документ рядом с распределением ответственности клиента и команды.

В завершении — два дополнительных вопроса и приглашение разобрать процесс. Отдельные повторяющиеся секции про функции, автоматизацию, права и преимущества объединены с соответствующими примерами.

## Референс и реализация движения

Референс: [десктопный Gumloop](https://www.gumloop.com/), изучен 8 сентября 2026 года, включая опубликованный JavaScript лендинга (chunk `2oa-228r5qv6_.js`). В источнике разобраны проекция точек и подписей сферы, управление указателем, пружинное следование, ограничение наклона, небольшая фиксация после отпускания и приостановка вне видимой области.

Здесь эти принципы реализованы собственным Canvas-компонентом для бизнес-связей. Иллюстрации, бренд, тексты и код сайта Gumloop в проект не перенесены. Для интерактивных сцен используются React, CSS и Canvas; библиотеки 3D и анимации не добавлены.

- Сфера: 720 точек, три дуги, глубина и связанные DOM-кнопки, пружинное движение. Canvas ограничен DPR 2. Отрисовка приостанавливается вне экрана и в скрытой вкладке.
- Карточки первого экрана медленно смещаются, пока процесс ручной и сцена видна. После запуска собираются в упорядоченную схему. Последовательность конечная, её можно повторить.
- Остальные переходы локальные: смена записи, раскрытие шага, обновление статуса и построение графика.
- `prefers-reduced-motion` отключает автоматическое вращение и декоративные переходы, сохраняя действия.

## Файлы

- `src/LivingLanding.tsx` — текущая страница и интерактивные сцены.
- `src/components/BusinessGlobe.tsx` — сфера, управление и примеры структур.
- `src/components/RequestDialog.tsx` — доступный модальный диалог с локальным черновиком.
- `src/components/Ui.tsx` — знак, иконки, появления секций, настройка уменьшенного движения.
- `src/styles/living.css` — новая композиция, состояния и адаптация.
- `src/styles/base.css`, `tokens.css` — общие элементы и типографика.
- `src/CompactV1.tsx`, `src/styles/site.css` — сохранённый первый промежуточный вариант; текущая страница их не импортирует.

Фактическая основа текста — `../LAMBDA_CRM_CONTEXT.md`. Кейс OKPODOLINS и команда из шести человек взяты из контекста. Записи, имена, суммы и показатели в интерфейсах демонстрационные и подписаны соответствующим образом. Измеренные приросты продаж или экономия времени не заявляются.

## Границы прототипа и проверка

Форма **не отправляет заявки**: сохраняет черновик только в этом браузере, явно сообщает об этом и позволяет удалить данные. Для реального приёма заявок нужно подключить согласованный канал или endpoint.

В браузере проверены оплата и четыре шага, три структуры и инспектор, перетаскивание и пауза сферы, задачи обеих карточек и связанные статусы, история менеджера, фильтр руководителя, три документа подхода, FAQ, мобильное меню, клавиатурное переключение ролей, сохранение и удаление тестового черновика, закрытие диалога по Escape. Тестовые данные формы удалены.

Проверены десктопы 1440 и 1024 px и мобильный экран 390 px. На проверенных размерах горизонтального скролла нет. Основная страница при 1280×720 занимает около 4180 px в исходном состоянии. Консоль проверенных сценариев — без ошибок. Production-сборка включает проверку TypeScript.
